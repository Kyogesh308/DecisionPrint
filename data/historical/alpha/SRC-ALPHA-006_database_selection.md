# Primary Database Selection — PostgreSQL
**Date:** 2024-03-20
**Type:** adr
**Author:** Marcus Chen
**Status:** Accepted

## Decision
We will use PostgreSQL 14 as the primary relational database for Platform v2.

## Rationale
PostgreSQL offers excellent JSON support, robust transactional integrity, and is well understood by the engineering team. It provides a solid foundation for our relational data models.
